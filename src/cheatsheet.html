Jev for Excel cheat sheet

Every formula on one page. Click any formula to copy it.

Jev is a "System One" AI model from TypeSafe AI. It doesn't write text. It makes a fast, calibrated decision about the text you give it: which of your options fits, where the text sits on a scale you define, or how likely a statement about it is to be true. Its answers are labels and numbers, which is exactly what a spreadsheet cell needs. You can filter, sort, chart and pivot them like any other data.

How it works: each formula sends a cell's text and your question to TypeSafe, using your own API key, and returns the answer to the cell. Fill a formula down a column of tickets, reviews or emails to classify every row. Questions about the same text go out together in one request. Answers are cached, so recalculating doesn't pay for them again.

Three kinds of question

Pick one option choice

Which of these labels fits the text?

returns technical

Add descriptions to tell similar labels apart. Include an other option. You can give 2 to 255 options.

Place on a scale score

Where does the text sit, from level 0 upwards?

returns 1.43 (between levels 1 and 2)

List 2 to 10 levels, lowest first. The result is probability-weighted, so it can fall between levels.

Yes or no noul

How likely is this statement to be true?

returns 0.93 (probability of yes)

Statements often work better than questions. You can add what counts as yes and as no after the statement.

JEV.ASK: every option through one function

The mode string

=JEV.ASK(mode, text, options…). The mode picks the question type and what to return.

Options, descriptions and questions

Options from a range

Keep your labels in cells and refer to them.

A header row works too, e.g. $B$1:$E$1. For scores, list the levels in order, lowest first.

Add descriptions

Put the description after a |, or use a two-column range.

In a two-column range, labels go in the first column and descriptions in the second.

Say what you're asking

Start any argument with ? to make it the question.

For yes/no, the two optional arguments describe what counts as yes, then what counts as no.

More than one field, and more

Several columns at once JEV.STATE

Combine a header row and a data row into named fields.

Refer to a field by its header name in `backticks`. A range passed as the text is sent as a list, and a cell holding JSON is sent as structured data.

Build on the results

Answers are ordinary values, so normal Excel works on them.

Send rows with low confidence to a person for review. Use choice:probs or noul to set your own cut-offs.

Available models JEV.MODELS

List the models your key can use.

Returns a table of names, descriptions and release dates. Choose a model in Home ▸ Jev. Pin a version such as jev-1.13.0 before tuning thresholds, so they don't shift when jev-latest changes.

When something goes wrong

You seeMeaning
#VALUE!A problem with the formula or key: an unknown mode, too few options, or a missing or invalid API key. Hover over the cell to read the message.
#N/AJev couldn't answer: it was unreachable, busy or rate-limited after retries. Recalculate to try again.
#BUSY!The answer is on its way.
blankThe text cell is empty. No call is made.

Tips

  • Ask one thing at a time. Split a compound question into several columns and combine them with AND or IF.
  • Keep labels short and stable. They're the values you'll filter on.
  • Freeze results you want to keep: copy the column and use Paste ▸ Values.
  • Mind cell limits. A cell holds at most 32,767 characters. For longer text, pass a range.

Example results are illustrative. Jev's actual answers depend on your text and the model version. In the VBA edition, write JEV("choice", …), JEV_STATE and JEV_MODELS, with the same arguments.
