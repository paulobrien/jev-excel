Jev for Excel is an unofficial Excel add-in, maintained by Paul O'Brien at Five Percent Studios.

## Other ways to get help

| Channel | Use it for |
|---|---|
| **Email:** [support@fivepercentstudios.com](mailto:support@fivepercentstudios.com) | Any question or problem with Jev for Excel. |
| **Community forum:** [GitHub Discussions](https://github.com/paulobrien/jev-excel/discussions) | Questions, tips and ideas, answered in public so others can find them too. |
| **Bug reports:** [GitHub Issues](https://github.com/paulobrien/jev-excel/issues/new) | Something that doesn't work as described. |

When you report a problem, please include:

- the Excel version and platform (Windows, Mac or the web), and whether you use the add-in or the VBA edition;
- the formula, with any sensitive text replaced by an example that still shows the problem;
- the exact error message, and what you expected to happen.

**Never send or post your TypeSafe API key.** If you share it by mistake, revoke it in your TypeSafe account straight away.

## Help yourself

- **Cheat sheet:** every formula on one page. Open it from the Jev pane in Excel (**Home ▸ Jev ▸ Cheat sheet**), or from **Help on this function** in Excel's **Insert Function** dialog.
- **[Troubleshooting](../README.md#troubleshooting)** lists common errors, such as `#VALUE!` and `#N/A`, with fixes.
- **[Installation](../README.md#installation)** covers adding the add-in to Excel on Windows, Mac and the web.
- **[Function reference](../README.md#function-reference)** explains every function, mode and output.

To see the full message behind an error, hover over the cell, or select it and click the error icon.

## Security issues

Please don't report security vulnerabilities in public. Email [support@fivepercentstudios.com](mailto:support@fivepercentstudios.com), or use GitHub's [private vulnerability reporting](https://github.com/paulobrien/jev-excel/security/advisories/new).

## Your TypeSafe account

Jev for Excel is free, but it needs a TypeSafe AI account and API key, and TypeSafe bills your account for Jev usage. Billing, API keys, rate limits and the Jev model itself are handled by TypeSafe AI. See [TypeSafe's documentation](https://docs.typesafe.ai/) or contact TypeSafe.
