# Support

Jev for Excel is an unofficial, open-source project maintained by Paul O'Brien in his spare time. Support is best-effort, through this repository.

## Help yourself first

Most problems are covered in the [README](../README.md):

- **[Troubleshooting](../README.md#troubleshooting)** lists common errors, such as `#VALUE!` and `#N/A`, with fixes.
- **[Installation](../README.md#installation)** covers adding the add-in to Excel on Windows, Mac and the web.
- **[Function reference](../README.md#function-reference)** explains every function, mode and output.

To see the full message behind an error, hover over the cell, or select it and click the error icon.

## Report a problem or ask a question

[Open an issue](https://github.com/paulobrien/jev-excel/issues/new) on GitHub. Please include:

- the Excel version and platform (Windows, Mac or the web), and whether you use the add-in or the VBA edition;
- the formula, with any sensitive text replaced by an example that still shows the problem;
- the exact error message, and what you expected to happen.

**Never post your TypeSafe API key.** If you post it by mistake, revoke it in your TypeSafe account straight away.

## Security issues

Please don't report security vulnerabilities in public issues. Use GitHub's [private vulnerability reporting](https://github.com/paulobrien/jev-excel/security/advisories/new) for this repository instead.

## Questions about your TypeSafe account

Billing, API keys, rate limits and the Jev model itself are handled by TypeSafe AI, not this project. See [TypeSafe's documentation](https://docs.typesafe.ai/) or contact TypeSafe.
